채움 프로토타입 정적 퍼블리싱 버전

1. 내 컴퓨터에서 확인
ZIP을 모두 압축 해제한 뒤 index.html을 브라우저로 여세요.
Node.js 설치, npm 실행, 빌드, 서버 설정, ChatGPT 로그인이 필요하지 않습니다.
index.html, css 폴더, js 폴더, favicon.svg는 서로 같은 위치 관계를 유지해 주세요.

2. GitHub Pages에 게시
ZIP 파일 자체가 아니라 압축을 푼 파일들을 저장소 최상위에 업로드하세요.
저장소를 열었을 때 index.html이 바로 보여야 합니다.
Settings → Pages → Build and deployment에서 Deploy from a branch를 선택하세요.
게시할 브랜치와 / (root)를 선택한 후 Save를 누르세요.
게시가 완료되면 Pages 설정에 표시되는 사이트 주소를 여세요.
저장소 파일 목록 주소와 실제 Pages 사이트 주소는 서로 다릅니다.
이미 다른 방식으로 Pages를 게시하고 있다면 이 폴더를 정적 게시 대상으로 사용하세요.

3. 보존한 내용
기존 요청 보드·등록·상세·재고 공유·보류·구매·입고·메모·품목·기록·설정 동작을 유지했습니다.
화면 문구, 샘플 품목, 아이콘, 색상, 간격, 스타일과 반응형 분기점은 기존 구현을 사용합니다.
새 기획안에서 제안한 기능이나 상태를 추가하지 않았습니다.

4. 데이터
체험 데이터는 현재 브라우저의 해당 주소에 저장됩니다.
기존 배포 주소, GitHub Pages 주소, 로컬 파일은 각각 저장 공간이 다를 수 있습니다.
처음 여는 주소에서는 기존 샘플 데이터로 시작합니다.

이 패키지에는 실행에 필요한 코드가 미리 포함되어 있습니다.
기존 개발용 프로젝트 전체를 업로드할 필요가 없습니다.
